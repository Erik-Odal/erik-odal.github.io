Autonomous Marine Docking

My MSc thesis at CPAC Systems focused on autonomous marine docking using Model Predictive Control. The work included route planning, vessel modelling, collision avoidance, simulator integration and initial tests on a real vessel.

Result: The work resulted in a granted Swedish patent.

Fluke Cable Tester

Cable testing required operators to transfer every measurement from a Fluke meter into an Excel report by hand. I developed a Python application that reads the meter over BLE, follows the active connection in Excel and stores validated results.

Result: A typical test was reduced from about 60 minutes to 6.

Brady Roll Refill Box

Brady label rolls could be rejected while usable material remained. I identified the DS2431 Smart Cell, mapped the remaining-material counter and built a standalone tool that validates and restores supported rolls.

Result: The finished tool is used in the workshop.

I was asked to investigate how HoloLens 2 could be used in the autonomy lab. I combined hand-tracking data with an existing BLE connection to a drone and implemented the control mapping in C++.

Working method

I normally start by breaking a problem into smaller technical parts. I then define what each part needs to do, how the interfaces fit together and what can be tested early. I prefer to build and integrate iteratively, since physical tests often reveal problems that are difficult to see when each part is developed in isolation.

My strongest areas are prototyping, system integration and troubleshooting physical systems. I also want to continue developing my knowledge in control theory and its use in systems that operate outside controlled lab conditions.
