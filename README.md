# Erik Laitala - Engineering Portfolio

Static portfolio prepared for GitHub Pages.

## Contents

- `index.html` - homepage
- `style.css` - complete shared stylesheet
- `projects/` - project case studies
- `assets/` - images, CV, thesis and project files

## Local preview

Run from the repository root:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publishing

Push the contents of this folder to the root of the public repository `erik-odal.github.io`.
